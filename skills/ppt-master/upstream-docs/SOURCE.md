# Bundled upstream documentation

These nine Markdown documents are the minimal documentation closure needed by
the `ppt-master` skill package. They were copied from
[`XREAL1TY/ppt-master`](https://github.com/XREAL1TY/ppt-master) at commit
[`b032c310e7506be9c3bbd198dfbec8f11af18e1a`](https://github.com/XREAL1TY/ppt-master/tree/b032c310e7506be9c3bbd198dfbec8f11af18e1a)
because the original package links to repository-level `docs/` files outside
the skill directory.

Only relative links were rewritten so the documents resolve inside this
portable skill package. The source skill's MIT license is retained at
[`../LICENSE`](../LICENSE).
