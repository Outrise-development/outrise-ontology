## Lookup method

Use Help Center search with the on-screen label plus a task noun (for example, “采购单 导入”, “结算利润 字段”, “广告 自动规则”, “MSKU 配对”). Open the result that matches the current UI module. Prefer current pages and recent update-log notes when the article sequence and UI conflict.
