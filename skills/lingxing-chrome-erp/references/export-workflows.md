# 领星快捷导出参考

仅在导出对应报表或排查下载故障时读取本文件。默认目标是交付用户所需的原始文件；准备周报素材同样到文件交付为止。

## 入口与使用边界

以下入口来自 Amazon 项目历史材料，并非本次对当前领星界面的在线验证。优先复用已登录的 Chrome 标签页和当前可见菜单；入口或控件变化时才查询官方帮助中心。

| 所需数据 | 历史入口 | 执行要点 |
|---|---|---|
| 产品表现 | `https://erp.lingxing.com/erp/productExpressionNew` | 选择店铺、站点、业务日期和用户所需维度，再用当前导出入口。 |
| 广告标准报告 | `https://ads.lingxing.com/amazon/create-report` | 按当前界面选择广告类型、报表类型、店铺、日期和粒度，创建所需报告。 |
| 广告操作日志 | 广告模块 → 操作日志，按“领星”“亚马逊”来源切换 | 只导出请求所需来源；需要两来源时分别提交和交付，不默认合并、去重。 |
| 运营日志 | 运营模块 → 运营日志 | 选择请求维度；未指定且不影响需求时沿用当前适用维度，不遍历所有维度。 |
| 广告下载任务 | `https://ads.lingxing.com/ak_download/download_center/download_report_log/index` | 历史下载中心入口；以当前可见的新旧中心和任务下载按钮为准。 |

- 链接只用于导航定位，不构造或猜测接口、下载端点及签名链接。
- 店铺、日期、类型、粒度等条件先从用户请求和上下文取得，只询问影响导出的缺失条件。
- 不把历史店铺、日期、广告类型或下载任务 ID 固化为新任务的默认值。
- 报表业务日期与下载任务创建日期是不同条件。历史广告业务日期曾使用美西时间，部分运营日志和任务创建时间曾使用北京时间；每次依当前页面标识处理，不能统一套用时区。

## 正常导出：最短可交付路径

1. 复用会话和入口，确认目标页面与所需报表相符。
2. 一次应用店铺、站点、业务日期、报表类型及必要筛选；确认控件已生效、页面加载结束。
3. 通过当前界面的原生导出按钮直接下载或提交后台生成任务。
4. 若是异步任务，记住对应任务 ID 或名称、必要范围及状态，待其可下载后执行原生下载。
5. 确认该下载属于本次请求、浏览器已完成下载，取得可交付文件的实际路径后结束。

这里的确认只针对筛选、任务和下载状态；不属于报表内容核验。

- 不打开 Excel，不读表头、统计行数、核对金额或日期覆盖，不计算 SHA256。
- 不读取看板指标与文件对账，不跨报表验证，不以“保证完整”为由扩展取数范围。
- 不默认生成筛选副本、清洗 CSV、索引 Excel、截图证据、审计报告、下载清单或 ZIP。
- 不为验证重复导出父 ASIN、子 ASIN、MSKU、周/月视图、日报或汇总版本。
- 若页面只支持整店导出，原样交付整店文件并说明包含其他产品，不在本地筛出产品副本。
- 需要的维度和粒度按请求选择；历史某维度导出为空或与另一维度重复，不构成每次重试全部维度的理由。

## 批量与异步任务

1. 按请求列出所需报表组合，仅作为会话内执行状态。
2. 提交一份后利用后台生成时间配置下一份，连续提交所需任务。
3. 全部提交后集中进入下载任务列表，按任务 ID、名称和状态下载。
4. 已提交未完成的任务先追踪状态；已下载任务不重复下载，除非明确失败或用户要求重取。

- 同一 Chrome 会话由一个执行者操作，避免标签页或筛选互相覆盖。
- 状态只在执行期间跟踪，不额外制作审计、哈希、索引或任务清单文件。
- 任务名称可辨识报表和业务日期即可；不要为了统一命名打开或重写原始文件。
- 若平台明确限制生成并发，按界面允许的数量排队，不无依据重复提交。

## 故障恢复：根据可见原因继续

一次失败只说明该次操作失败，不能直接判定功能永久不可用。先定位具体原因，尝试可用路径；不要把下载排查扩展成数据验证。

### 筛选没有生效

- 店铺选择器要看到目标店铺确实进入“已选”或显示为当前选择；仅点击候选项不代表已应用。
- 日期直接填入后若重置、未应用或被清空，改用可见日期面板选择并确认，不反复运行同一失败输入。
- 等待筛选控件与加载状态稳定后导出，不用读取业务指标证明筛选生效。
- 页面明确限制日期跨度或任务数量时，按允许范围拆分日期或批次，保持用户所需数据范围并简短说明拆分。

### 下载中心找不到任务

- 先检查本次提交是否已有成功提示、任务 ID 或任务名称，避免盲目再次提交。
- 检查下载列表的创建日期筛选、时区、状态和报表类型；按本次实际创建时间放宽列表条件。
- 报表可能查询历史业务日期，但下载任务是今天创建；不要因此修改原报表业务周期。
- 有目标 ID 时优先定位该任务；列表有分页或当前可见新旧中心时，在相应入口查找。
- 历史链接失效时回到当前菜单，必要时按可见功能名查询官方帮助，不猜隐藏接口。

### 生成较慢或下载文件未出现

- 查看目标任务状态与浏览器下载状态，区分“生成中”“可下载”“传输中”和“失败”。
- 等待可按约 5、10、20、30、60 秒逐步延长；单次等待不超过 60 秒，并根据可见状态变化调整。
- 长时间无变化时检查失败说明、任务所在中心和当前可用入口；换有依据的恢复路径，不持续空刷或重复建任务。
- 浏览器已开始下载时，先检查实际保存目录、文件名、下载提示及临时下载文件状态，不立刻再次点击下载。
- 文件已完成但不在预期目录时，使用浏览器显示的实际保存位置；用户要求特定目录时再保存或移动到该目录。
- 只用文件存在和下载完成状态确认可交付，不解压、开表或核对文件内容。

### 下载被拦截或入口失败

- 读取浏览器或页面给出的原因，检查当前可用的新旧下载中心及目标任务原生下载入口。
- 可使用浏览器正常支持的重试、恢复或保存操作；不绕过安全禁令、组织策略或明确的权限限制。
- 不提取账号凭据、Cookie、令牌或私有接口，不拼接签名链或改用隐藏 API 绕过原生下载限制。
- 原生入口暂时失败时继续排查其他可见可用入口；平台明确失败且可重新生成时再针对该任务重试。

### 原生文件确实无法取得

- 已有可见故障证据且原生路径无法解决时，可按用户已确认的偏好提取同范围页面表格并保存 CSV。若当前请求明确只接受领星原生报表、不接受页面提取，则继续排查原生路径，无法取得时说明具体阻点，不擅自替换。
- 该文件必须标为“页面提取”，不能冒充领星原始导出；只声明实际取得的范围。
- 只能取得当前页或部分分页时，明确交付范围与缺失部分，不虚称全量；能正常继续分页时继续完成请求范围。
- 此处 CSV 是原生下载不可用时的交付替代，不是常规导出后的清洗副本。
- 不额外采集截图留证，不为证明页面内容完整而开展金额、行数或跨报表对账。
- 平台明确无数据、权限不足、登录失效、验证码或服务不可用时，说明具体阻点；只有确实需要用户动作时才请求对应操作。
- 没有取得文件时如实说明，不把仅创建成功的任务报告为已下载。

## 周报与交付

- “准备周报素材”先复用用户提供或上下文已有且范围已明确适用的原表，只补缺失项；依据用户说明或已知导出条件判断适用，不为复用开表核验。原始文件交付即结束，不生成分析、报表或复盘。
- “生成周报／分析数据”先复用上下文已有适用文件，仅补取报告必需的缺失资料，再进行必要计算和撰写。
- 分析任务可读取文件，但不自动追加全面核验或额外维度导出；用户明确要求核验时才进入对应工作。
- 默认回复只列已下载文件和实际路径、必要的范围说明、尚未取得的项目。
- 范围说明仅在有整店数据、拆分批次、页面提取或其他影响使用的差异时补充，避免把内部排查过程写成交付报告。
