# 人工验收与四个评估维度

以下场景使用合成演示工作区。所有品牌、规格和内容均为虚构；三个 SVG 是自制示意素材，不作平台图片规范示范。

| 维度 | 可观察的验收结果 |
| --- | --- |
| Agent 可读性 | 通过浅层目录与 ID 定位记录；普通文本工具可读取事实、关系、块和策略；不依赖浏览器或编辑器私有 JSON。 |
| Agent 可访问性 | CLI 与 API 能读取规范文档、解析投影与 Listing 上下文；受控写入有 revision 检查、字段校验和协作锁；Agent 建议可审阅、不能自行确认。 |
| 人的可读性 | 产品目录、属性继承来源、营销策略、素材和 Listing 状态清楚；英文商品文案与中文操作界面分开；未知或未放置内容可见。 |
| 人的操作易用性 | 能在工作台完成编辑、恢复继承、素材上传、媒体排序、确认、差异审阅和导出；冲突与未保存内容有明确提示。 |

## 关键场景

1. **动态文案**：更改工作区 `ui/zh-CN.md` 内一项标签，保存后页面更新；无需改前端源代码或重新构建。改变模板中的固定模块顺序，所有引用实体应用新布局。
2. **目录管理**：查看一个品牌、一条产品线、一个 SPU 和三个 SKU；创建允许类型的新记录；父级类型不合法或引用循环时被拒绝；归档后默认目录隐藏记录。
3. **属性继承**：Black 继承 SPU 重量，Olive 使用独立重量。修改 SPU 后只有继承值跟随更新；Olive 恢复继承后删除本地重量字段。SKU 无法覆盖品牌、型号和材质。
4. **混合编辑**：可以编辑普通富文本、增删允许的块和调整区域内顺序；不能删除模板固定模块，也不能编辑来源只读块。模板把 notes 禁止某类型后，原内容仍出现在未放置区。
5. **素材管理**：上传文件并关联 SPU 或 SKU，检查原始名称、大小、MIME、hash 和预览/下载。Listing 选择素材并调整顺序，刷新后保持顺序。
6. **平台草稿**：分别查看 Amazon、Shopify、TikTok Shop 模板；共享文案、SKU 内容覆盖及媒体分配保留，所选 SKU 不得来自其他 SPU。不出现“已发布”或虚构店铺同步状态。
7. **确认与失效**：人工确认事实与策略，记录 Listing 输入后确认 Listing。之后更改 SPU、所选策略或媒体实际文件，Listing 提示复核；只调整模板布局不触发业务内容失效。
8. **Agent 建议**：导出上下文，提交候选 Markdown。导入后只显示建议与差异，人工采纳前不替换当前 Listing。候选不允许伪造已确认状态。当前源版本改变后，旧建议不能静默覆盖修改。
9. **冲突与错误**：两个客户端基于相同 revision 编辑，后提交者得到 409；非法字段类型、重复 ID、损坏 YAML、丢失引用和路径穿越有检查结果，源文件不被自动覆写。
10. **导出与保存**：导出的 MD 可独立阅读，JSON 是派生快照；重启后本地修改保留，演示初始化不覆盖已有文件；工作区内容不被意外加入 Git。
11. **可访问操作**：键盘可到达导航、表单、编辑、保存、取消、确认及弹窗；窄屏内容保持可读，长名称、空数组和未填写字段有正常显示。

## 自动化边界

协议测试覆盖解析往返、目标块替换、未知元数据保留、模板未放置规则与继承；后端集成测试覆盖引用、来源策略、revision 冲突、路径、确认快照、输入失效、建议采纳和导出。前端构建及浏览器检查覆盖动态文案、主要编辑流程和错误提示。

不为合成数据的英文文案逐字编写测试，也不以快照测试证明平台发布有效。性能以本地低频、小数据集交互可用为目标；本期没有并发压测或生产 SLA。
