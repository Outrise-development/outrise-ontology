## 字体与可编辑性

用户在第 5 页新增的两条标签采用“字由经典黑 Bold”。本次保留该样式，PPTX 直接保留 Canva 导出包，没有强制替换为 Noto 或重写字体嵌入。其他文字继续使用六个既有品牌 face。旧版仅接收品牌字体的规范化工具因此不适用于这份导出。

`validation/canva-pdf-fonts.json` 的两条字体提示恰好对应这两个用户标签，其他非预期字体为零；`validation/release-audit.json` 记录了明确的用户样式例外。没有把它表述为“全稿仅六个品牌字体”或“六个完整字体重新嵌入”。编辑能力与字体处理以实际 Canva 导出为准，部分箭头仍是独立 SVG 图形组件；本轮未在桌面 PowerPoint 应用内打开。

本地第 5 页标签使用 Noto 作为离线重建替代；实际最新字体和排版以 Canva 导出及快照为准，不声明二者像素一致。重跑验证使用包含 pdfplumber 的 Python 执行 `tools/validate_release.py`；它只读取文件并将审计 JSON 输出到标准输出。
